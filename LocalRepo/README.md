# Local Repository Practice

A beginner-friendly web development project created to practise HTML, CSS, Git, and GitHub workflows.

## About the Project

This repository documents my hands-on experience with creating a local Git repository, developing a simple webpage, and managing changes using Git and GitHub.

## Technologies Used

- **HTML5** – Webpage structure and content
- **CSS3** – Styling and layout
- **Git** – Version control
- **GitHub** – Repository hosting and project management

## Project Structure

```text
LocalRepo/
├── README.md
├── index.html
└── style.css
```

## How to Run

1. Clone or download this repository.
2. Open the `LocalRepo` folder.
3. Open `index.html` in a web browser.
4. Explore the webpage and its styling.

## Learning Outcomes

- Creating and organizing a local Git repository
- Building a basic HTML webpage
- Applying CSS styling
- Tracking changes with Git
- Committing and pushing updates to GitHub
